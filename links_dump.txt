Overview:
SMPL is an easy-to-use, realistic, model of the of the human body that is useful for animation and computer vision.
SMPL lets you create realistic human body shapes with realistic deformations.
Available here is a version of SMPL that is similar to that described in
[this paper.](http://files.is.tue.mpg.de/black/papers/SMPL2015.pdf)

Dependencies
Numpy is required for running this script. Numpy is a Python module that can be installed following the instructions given
[here](http://docs.scipy.org/doc/numpy/user/install.html)
or
[here](http://blog.animateshmanimate.com/post/115538511578/python-numpy-and-maya-osx-and-windows)
Please make sure you have numpy installed on your computer and accessible through Maya's Python. We are working towards removing this dependency.

SMPL for Blender
This Blender add-on allows you to add SMPL skinned meshes to your current Blender scene. Each imported SMPL mesh consists of a shape specific rig, as well as shape keys (blend shapes) for shape and pose correctives.
Requirements: Blender 2.80+
Additional dependencies: None
Used SMPL model: SMPL v1.0 with 10 shape components
[Installation instructions](https://download.is.tue.mpg.de/download.php?domain=smpl&sfile=README.md)
[Download SMPL Blender Add-on (20210611, 34MB)](https://download.is.tue.mpg.de/download.php?domain=smpl&sfile=smpl_blender_addon_20210611.zip)
SMPL for Unreal Plugin (USMPL)
The USMPL plugin allows a user to put the SMPL model in Unreal Engine and control its pose using ROS in real-time. The plugin is available at https://github.com/robot-perception-group/USMPL. Following are the gender-specific models for the USMPL plugin.
